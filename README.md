# Em desenvolvimento!

## Comprar ou Esperar?

Agente financeiro de IA que decide se um usuário tem condições de arcar com segurança com uma despesa solicitada.

O usuário pergunta **"Eu posso comprar esse Notebook?"**

Ela vai considerar mais do que somente o saldo atual. O agente deve levar em conta despesas recorrentes, pagamentos pendentes, gastos essenciais, receitas confirmadas, opções de pagamento disponíveis e detalhes relevantes em mensagens e imagens.

Para cada solicitação, o agente decide se o usuário deve pagar o valor integral, pagar parcialmente, parcelar, aguardar ou não prosseguir. A recomendação deve ser personalizada: dois usuários com o mesmo saldo podem receber respostas diferentes com base em seus compromissos, prioridades, preferências de pagamento e disposição para ajustar despesas flexíveis.
